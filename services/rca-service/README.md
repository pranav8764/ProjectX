# RCA Service

Owns root cause analysis workflows and reports.

## Responsibilities

- Generate problem summaries
- Build event timelines
- Identify repeated failure patterns
- Produce probable causes with citations
- Surface missing data
- Store RCA reports

## Owns Schema

`rca`

## Depends On

- `rag-service`
- `asset-service`
- `graph-service`
- `ai-orchestrator-service`
