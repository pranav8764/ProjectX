# Infrastructure

Local infrastructure, database migrations, storage setup, deployment placeholders, and observability config live here.

## Folders

- `db`: PostgreSQL schemas, pgvector setup, migrations, seeds
- `docker`: Docker notes and helper files
- `k8s`: Kubernetes base and overlays
- `helm`: future Helm chart placeholder
- `observability`: OpenTelemetry/logging/metrics config
- `terraform`: future cloud infrastructure modules
